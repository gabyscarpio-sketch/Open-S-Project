Prompts para el Backend de IA (FastAPI)
Usa estos prompts cuando tengas abierto un archivo dentro de tu directorio backend-ia, como main.py.

1. Para crear la estructura básica de la API:
"En el archivo main.py, genera una API básica de FastAPI con un endpoint raíz / que devuelva un JSON {"status": "ok"}. Incluye la configuración de CORS para permitir todas las origins, métodos y headers para desarrollo."

2. Para definir los modelos de datos (Pydantic):
"Usando Pydantic, crea un modelo llamado PatientQueryRequest que tenga dos campos: patient_id (un entero) y prompt_text (un string)."

3. Para la lógica del Asistente Virtual:
"Crea un endpoint POST en /api/v1/assistant/ask que acepte el modelo PatientQueryRequest. Dentro de la función, simula una llamada a un LLM y devuelve una respuesta en JSON con una clave response que contenga un texto de ejemplo."

4. Para conectar con Supabase (si el backend lo necesita):
"Escribe una función asíncrona llamada fetch_patient_history que tome un patient_id como argumento. Debe inicializar el cliente de Supabase usando las variables de entorno SUPABASE_URL y SUPABASE_KEY, y luego consultar la tabla 'medical_records' para obtener todos los registros que coincidan con el patient_id."

## 🎨 Prompts para el Frontend (Next.js / React)
Usa estos prompts cuando estés trabajando en los archivos de tu directorio frontend.

1. Para crear un componente de UI:
"Usando React, TypeScript y Tailwind CSS, crea un componente PatientCard. Debe aceptar name, age y last_visit como props y mostrarlos en una tarjeta con un borde sutil y sombra."

2. Para configurar el cliente de Supabase:
"En un nuevo archivo dentro de frontend/lib/supabaseClient.ts, inicializa y exporta el cliente de Supabase para el navegador. Utiliza las variables de entorno NEXT_PUBLIC_SUPABASE_URL y NEXT_PUBLIC_SUPABASE_ANON_KEY."

3. Para hacer una llamada a tu API de FastAPI:
"En un componente de React, crea una función handleSendMessage que tome un texto como argumento. Esta función debe hacer una petición POST asíncrona usando fetch al endpoint /api/v1/assistant/ask de mi backend. Debe enviar un cuerpo JSON con patient_id (usa un valor de ejemplo como 123) y prompt_text. Luego, imprime la respuesta en la consola." Nota: Replit se encarga de enrutar la petición. No necesitas la URL completa del backend, solo la ruta relativa.

4. Para crear una página completa:
"Genera una página de chat para el asistente virtual usando el App Router de Next.js. La página debe tener un área para mostrar los mensajes y un formulario en la parte inferior con un input de texto y un botón de 'Enviar'. Gestiona la lista de mensajes usando el hook useState."

## 💡 Consejos Clave para tus Prompts
Sé Específico sobre el Archivo: Comienza tu prompt diciendo "En este archivo..." o "En el archivo components/Chat.tsx...". El AI de Replit tiene conciencia del contexto del archivo que tienes abierto.

Menciona las Tecnologías: Di explícitamente "usa Tailwind CSS", "usa Pydantic", "usa el hook useEffect". Esto guía al modelo para que genere el código idiomático correcto.

Itera: No pidas todo de una vez. Primero, pide el componente. Luego, pide añadirle el manejo de estado. Después, pide que haga la llamada a la API. Trabajar en pequeños pasos te da un código más limpio y controlable.
